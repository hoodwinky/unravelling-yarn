## Capture status
**Automatic chat capture is not connected.** This repository cannot listen to conversations or retrieve all ChatGPT chats. For now, add an idea through Issues, a pull request, or the hub's local draft form. A future integration needs an authorized input source and a private review stage before public publication. See [the integration plan](docs/capture.md).

## A thread's record
Each project keeps a stable ID, title, summary, stage, connections, a practical next step, source description, and publication approval. Link developments to the same thread so ideas accumulate instead of multiplying into duplicates.

## Creative direction
Orange sparks, emerald greenery, purple sky, blue water, pink blossoms, gold light. Original King of Hearts and Ace of Spades motifs, playful feline mischief, fireworks and flourishing gardens. Joy, community and an invitation to join in.

## Contribute and reuse
Open an issue or submit a pull request. Contributions must be yours to share publicly. Code and original project text are offered under the [MIT licence](LICENSE), including commercial reuse with its notice. Third-party names, brands and assets retain their own rights. An idea is an invitation to develop it, not a claim that its proposed partners have agreed.

## Publication boundary
Publish approved project summaries. Keep raw chats, credentials, personal matters and Evidence Engine case records outside this public repository. In a public repository, issues, commits and pull requests are public too.
